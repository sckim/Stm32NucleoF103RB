# 05_ADC_Potentiometer_PWM_HAL_c

> 계층: **HAL + DMA** — Claude 작성, 검토 전 (PlatformIO 빌드만 확인)

가변저항으로 LED 밝기를 조절한다. **센서 → 처리 → 액추에이터**를 ADC(입력)와 TIM PWM(출력)으로 가장 단순하게 보여 주는 예제이며, 이동 평균, 히스테리시스, 감마 보정을 함께 익힌다.

## 핵심 학습 내용

- **입력**: PA1(ADC1_IN1) 연속 변환 + DMA 로 최신값을 항상 변수에 유지. main 이 20ms 마다 읽는다.
- **처리**: 8샘플 이동 평균(노이즈), ±2 히스테리시스(미세 떨림에 출력이 깜빡이지 않게), **감마 보정**(밝기 ≈ 입력², 사람 눈은 밝기를 로그에 가깝게 느낌).
- **출력**: TIM2_CH1(PA0) 1kHz PWM, `CCR1 = 0..1000`. 정수 연산으로 `duty = adc² / 16765`.
- 온보드 LD2(PA5)는 PWM 채널이 아니어서 외부 LED 를 PA0 에 연결한다.

## 배선 / 동작

PA1 에 가변저항 가운데 단자(양끝 3.3V/GND), PA0 → 330Ω → LED → GND. UART(115200)로 0.5초마다 ADC 값과 듀티 출력.

## ISR vs 콜백

인터럽트를 사용하지 않는다 (ADC 는 DMA 가 갱신).
