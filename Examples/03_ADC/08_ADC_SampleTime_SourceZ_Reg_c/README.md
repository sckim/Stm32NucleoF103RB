# 08_ADC_SampleTime_SourceZ_Reg_c

> 계층: **레지스터(CMSIS)**, HAL 미사용 — 검토 전 (PlatformIO 빌드만 확인)

교안 「ADC」(주변장치 3) 6.2절(샘플-홀드와 입력 임피던스)의 실습이다.
샘플링 시간 `SMPx`가 짧고 소스 저항이 크면 내부 샘플-홀드 커패시터가 다 충전되지 못해 값이 틀린다. 그 오차를 **직접 일으켜 LSB로** 확인한다.

## 핵심 학습 내용

- **샘플-홀드는 RC 충전이다**: 샘플링 시간 Ts 동안 C_ADC(최대 8 pF)를 외부 저항 R_AIN + 샘플링 스위치 R_ADC(최대 1 kΩ)로 충전한다. 오차 1/4 LSB 이하 조건(DS5319 식 1)은 다음과 같다.
  `R_AIN < Ts / (f_ADC · C_ADC · ln(2^14)) − R_ADC`
- **C_ADC에는 직전 채널의 전압이 남는다**: 랭크 1에서 GND(PA1)를 변환해 커패시터를 0 V로 비운 뒤, 랭크 2에서 시험 입력(PA0)을 변환한다. 덜 충전된 만큼 값이 낮게 나온다.
- **스캔 모드와 EOC**: 스캔 모드에서는 EOC가 시퀀스 마지막 변환 뒤에만 선다(RM0008 11.12.2 SCAN 주석). 그때 DR에는 마지막 랭크(CH0) 결과가 있으므로 DMA 없이 읽을 수 있다.
- **레지스터로 하는 ADC 초기화 순서**: `ADON`(전원) → tSTAB 대기 → `RSTCAL` → `CAL` → 채널·샘플 시간·시퀀스 → `EXTSEL = 111`, `EXTTRIG = 1` → `SWSTART`.

## 계산표 (ADCCLK 10.67 MHz, 식 1)

| SMP | Ts [사이클] | Ts [µs] | R_AIN 최대 [kΩ] |
|---|---|---|---|
| 000 | 1.5 | 0.14 | 0.8 |
| 001 | 7.5 | 0.70 | 8.1 |
| 010 | 13.5 | 1.27 | 15.3 |
| 011 | 28.5 | 2.67 | 33.4 |
| 100 | 41.5 | 3.89 | 49.1 |
| 101 | 55.5 | 5.20 | 66.0 → 50(표 47 상한) |
| 110 | 71.5 | 6.70 | 85.3 → 50 |
| 111 | 239.5 | 22.45 | 288 → 50 |

데이터시트 표 48(14 MHz 기준)과 같은 식이다. ADC 클럭이 느릴수록 같은 사이클 수에서 허용 저항이 커진다.

## 배선

```
PA1(A1) ── GND
3V3 ── 10 kΩ ──┬── 10 kΩ ── GND          (약 1.65 V, 테브난 저항 5 kΩ)
               └── R_S ── PA0(A0)         R_S = 점퍼 / 10 kΩ / 47 kΩ / 100 kΩ
```

## 동작

USART2(115200 8N1)로 2초마다 다음 표를 출력한다. LD2가 표마다 토글된다.

```
SMP  Ts[cyc]  Ts[us]  RAINmax[kOhm]  CH0 raw   err[LSB]
  0      1.5    0.14          0.8     ....      ....
  ...
  7    239.5   22.45         50.0*    2048         0
```

실측값은 배선과 R_S에 따라 달라진다. **R_S를 바꿔 가며 "오차가 사라지는 SMP"가 계산표와 맞는지 확인하는 것이 이 실험의 질문이다.**

## 생각해 볼 것

- 식 1에는 소스 쪽 커패시턴스가 없다. PA0와 GND 사이에 1~10 nF를 달면 결과가 어떻게 바뀌는가? 생체신호 전단의 안티앨리어싱 RC 필터가 ADC 입력에 어떤 이점과 대가를 주는가?
- 랭크 1을 GND 대신 3.3 V로 바꾸면 오차의 부호는 어떻게 되는가?
