# 22_ADC_AnalogWatchdog_HAL_c

> 계층: **HAL** + DMA — Claude 작성, 검토 전 (컴파일만 확인)

ADC가 변환할 때마다 **하드웨어가** 결과를 상·하한과 비교하고, 창(window)을 벗어나면 인터럽트를 낸다. CPU가 값을 계속 읽어 비교할 필요가 없다.

## 핵심 학습 내용

- **아날로그 워치독(AWD)**: 과전압/저전압/과전류 보호처럼 "범위 이탈 감지"에 적합.
- **설정 레지스터**: `ADC1->HTR/LTR`(상·하한, 이 예제는 1000~3000 ≈ 0.81~2.42V), `CR1.AWDEN`(bit23), `AWDSGL`(bit9, 단일 채널), `AWDCH`(감시 채널), `AWDIE`(bit6), `SR.AWD`(bit0, 이탈 플래그).
- **인터럽트 폭주 함정**: 창을 벗어난 상태에서는 **매 변환마다** AWD가 다시 발생한다(초당 수만 회). 그래서 콜백에서 AWD 인터럽트를 끄고, main이 창 안으로 돌아온 것을 확인한 뒤 다시 켠다(무장/해제 패턴).
- 연속 변환 + DMA로 최신값을 변수에 자동 저장 (DMA 전송 완료 인터럽트는 NVIC에서 허용하지 않아 ISR 부하 없음).
- ADC 클럭 10.67MHz, 샘플 239.5 사이클 → 약 42kSPS.

## 배선 / 동작

PA0(A0)에 가변저항을 연결하고 0~3.3V로 돌린다. 창을 벗어나면 LD2가 켜지고, 창 안으로 돌아오면 main이 LD2를 끄고 AWD를 다시 무장한다. 200ms마다 현재 값과 상태를 UART(115200)로 출력.

## ISR vs 콜백

`ADC1_2_IRQHandler`(진짜 ISR) → `HAL_ADC_IRQHandler()` → `HAL_ADC_LevelOutOfWindowCallback()`(이 파일).

## 관련 예제

`21`(DMA 스캔), `20`(폴링).
