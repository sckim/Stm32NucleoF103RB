# 23_ADC_Vrefint_VDDA_HAL_c

> 계층: **HAL** — Claude 작성, 검토 전 (컴파일만 확인)

내부 기준전압(Vrefint)을 측정해 실제 VDDA를 역산하고 ADC 값을 보정한다.

## 핵심 학습 내용

- **ADC는 "VDDA 대비 비율"을 변환한다**: `mV = raw × 3300 / 4095`는 VDDA가 정확히 3.3V일 때만 맞다. USB/배터리 전원에서 VDDA가 3.0~3.4V로 변하면 오차가 생긴다.
- **보정 원리**: Vrefint(전형 1.20V, 온도·전원에 거의 무관)를 측정하면 `raw_vref = Vrefint × 4095 / VDDA` → `VDDA = Vrefint × 4095 / raw_vref`. F1은 이후 시리즈와 달리 개별 공장 교정값이 없어 데이터시트 전형값을 쓰며 개체 편차(1.16~1.24V)가 남는다.
- **내부 채널 사용법**: 채널 17(Vrefint), `ADC1->CR2.TSVREFE`(bit23)로 활성화(HAL이 자동 설정). 소스 임피던스가 높아 샘플 시간을 길게(239.5 사이클, 데이터시트 최소 17.1µs; 여기서는 약 23.6µs) 잡아야 정확하다.
- 16회 평균으로 잡음 감소.

## 동작

1초마다 Vrefint로 계산한 VDDA와, PA0의 "측정 VDDA 기준 mV" / "3.3V 가정 mV"를 함께 UART(115200)로 출력해 차이를 비교한다.

## 인터럽트

사용하지 않는다 (폴링 변환).

## 관련 예제

`20_ADC_Temperature`(내부 채널 사용), `22`(PA0 입력).
