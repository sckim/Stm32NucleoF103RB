# 06_I2C_OLED_SSD1306_HAL_c

> 계층: **HAL** — Claude 작성, 검토 전 (컴파일만 확인)

I2C 로 **SSD1306 128x64 OLED**를 구동한다. RAM 에 1KB 프레임버퍼를 두고 그린 뒤 통째로 전송하는 정석 패턴이며, 선/사각형/공 애니메이션과 프레임 번호·FPS 숫자를 표시한다.

## 핵심 학습 내용

- **SSD1306 구조**: 8 페이지 x 128 열, 1바이트 = 세로 8픽셀. I2C 제어 바이트 `0x00`=명령, `0x40`=표시 데이터.
- **초기화 시퀀스**: 차지 펌프(`0x8D 0x14`), 수평 주소 지정(`0x20 0x00`), 세그먼트/COM 방향 등 명령 나열과 의미.
- **프레임버퍼 패턴**: 그리기 함수는 `fb[]`만 수정하고 `oled_flush()`가 화면 전체를 전송한다. Bresenham 선, 사각형, 3x5 숫자 글꼴(문자 일부만 내장, 표를 확장해 사용).
- **속도**: 400kHz 고속 모드에서 1024바이트 ≈ 23ms → 약 40 FPS. 측정된 FPS 가 화면과 UART 에 표시된다.

## 배선 / 동작

OLED(I2C 4핀): VCC=3.3V, GND, SCL=PB6, SDA=PB7, 주소 0x3C. 모듈에 풀업이 없으면 4.7kΩ 추가.

## ISR vs 콜백

인터럽트를 사용하지 않는다(블로킹 I2C). DMA 전송으로 바꾸면 CPU 부하를 줄일 수 있다.
