# 06_SPI_MAX7219_HAL_c

> 계층: **HAL** — Claude 작성, 검토 전 (PlatformIO 빌드만 확인)

**MAX7219 8x8 LED 매트릭스** 구동. 16비트 프레임(레지스터 주소 + 데이터)과 CS(LOAD) 상승 에지 반영이라는 시프트 레지스터형 SPI 장치의 전형을 익힌다.

## 핵심 학습 내용

- **프레임**: `[reg][data]` MSB 먼저, **CS 가 High 로 올라가는 순간** 반영. 캐스케이드하면 칩 수만큼 프레임을 연달아 보낸 뒤 CS 를 올린다.
- **레지스터**: `0x01~0x08` 행 데이터, `0x09` 디코드(매트릭스는 0), `0x0A` 밝기, `0x0B` 스캔 제한, `0x0C` 셧다운, `0x0F` 디스플레이 테스트.
- 프레임버퍼 `fb[8]` 에 그리고 `flush()` 로 8행 전송. 행 스캔, 튕기는 점, 확장 사각형, 밝기 페이드 애니메이션.
- 글자 표시는 문자별 8x8 비트맵을 `fb` 로 복사해 옆으로 밀면 스크롤이 된다(표 추가로 확장).

## 배선 / 동작

MAX7219 매트릭스 모듈: VCC=5V, GND, CLK=PA5, DIN=PA7, CS(LOAD)=PA4. PA5 는 LD2 와 같은 핀. SPI 송신 전용, 1MHz.

## ISR vs 콜백

인터럽트를 사용하지 않는다 (블로킹 SPI).

`03_SPI_OLED_SSD1306_HAL_c`(프레임버퍼 패턴), `02_SPI_DMA_Fullduplex_HAL_c`.
