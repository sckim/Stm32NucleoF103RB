# 40_SPI_Loopback_HAL_c

> 계층: **HAL** — Claude 작성, 검토 전 (컴파일만 확인)

SPI1 마스터의 MOSI를 MISO에 연결(루프백)해 송수신 데이터 일치를 확인하고, 클럭 분주비별 전송 속도를 측정한다.

## 핵심 학습 내용

- **SPI 설정** (RM0008 25장): SPI1은 APB2(64MHz)에 연결. `CR1.BR[2:0]`으로 /2~/256 분주 (/64 → 1MHz, /4 → 16MHz). `MSTR=1`, `CPOL=0/CPHA=0`(모드 0: 유휴 Low, 첫 에지 샘플), 8비트, MSB 먼저. `SSM=1, SSI=1`로 NSS를 소프트웨어 관리.
- **전이중 1바이트**: `DR`에 쓰면 송신 시프트가 시작되고 같은 클럭에 수신도 일어나며, `SR.RXNE` 후 `DR`을 읽는다. `HAL_SPI_TransmitReceive`.
- **자체 검증(loopback) 기법**: 외부 장치 없이 송신 == 수신을 비교해 PASS/FAIL. 배선/설정 오류를 가르는 표준 방법.
- **성능 측정**: 분주비 /256, /64, /16, /4로 바꿔 가며 256바이트 전송 시간을 **DWT 사이클 카운터**로 재고 실제 비트율을 계산해 출력한다. 분주비를 낮춰도 폴링 오버헤드 때문에 이론 속도에 못 미치는지 비교해 본다.

## 배선

`PA7 ── 점퍼 ── PA6`. 점퍼를 빼면 FAIL (음성 대조).

## 인터럽트/DMA

사용하지 않는다 (폴링). DMA 버전은 `41_SPI_DMA_Fullduplex_HAL_c`.
