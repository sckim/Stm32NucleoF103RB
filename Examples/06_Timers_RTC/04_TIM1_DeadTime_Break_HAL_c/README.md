# 04_TIM1_DeadTime_Break_HAL_c

> 계층: **HAL** + 고급 타이머 TIM1 — Claude 작성, 검토 전 (컴파일만 확인)

모터 구동(하프브리지)에서 상·하단 스위치가 동시에 켜져 전원이 단락(shoot-through)되는 것을 막는 기능을 다룬다: **상보 PWM + 데드타임 + 브레이크**.

## 핵심 학습 내용

- **상보 출력**: `TIM1_CH1`(PA8)과 `TIM1_CH1N`(PB13)은 서로 반전된 신호이다. 20kHz, 듀티 50% (`PSC=0`, `ARR=3199`, `CCR1=1600`, TIM1은 APB2 64MHz).
- **데드타임**: 한쪽이 꺼진 뒤 일정 시간 지나서 다른 쪽이 켜지도록 사이 공백을 삽입한다. `데드타임 = DTG × t_DTS`, `t_DTS = 1/64MHz = 15.6ns`. HAL의 `DeadTime` 인자는 `BDTR.DTG[7:0]` 값 그대로이며, `DTG=64` → 약 1µs. (DTG ≥ 128이면 성긴 단위로 더 긴 데드타임)
- **브레이크**: `TIM1->BDTR.BKE=1`, `BKP=1`(High 활성)이면 브레이크 입력(PB12) 시 하드웨어가 `MOE`를 0으로 만들어 **출력 전부를 즉시 차단**한다. `SR.BIF=1` + 브레이크 인터럽트. `AOE=0`이므로 해제 후 소프트웨어가 `MOE`를 다시 켜야 한다.
- 고급 타이머는 출력을 켜기 위해 `MOE`(Main Output Enable) 비트가 필요하다는 점(범용 타이머와의 차이).

## 관측 / 시험 (오실로스코프 또는 로직 분석기)

1. PA8과 PB13을 동시에 보면 두 신호가 겹치지 않고 사이에 약 1µs의 공백이 있다.
2. B1(PC13)을 누르면 소프트웨어 브레이크(`TIM1->EGR.BG`) → 두 출력이 즉시 꺼지고 LD2가 켜진다. 2초 뒤 `MOE`를 다시 켜서 PWM 재개.
3. 외부 신호로 시험하려면 PB12에 3.3V를 인가.

## ISR vs 콜백

`TIM1_BRK_IRQHandler`(진짜 ISR) → `HAL_TIM_IRQHandler()` → `HAL_TIMEx_BreakCallback()`(이 파일): 브레이크 발생 통지.
