출력 비교와 CCR 전진: 채널마다 다른 주파수

출력 비교(Output Compare)는 카운터가 CCR 값과 같아지는 순간 하드웨어가 핀을 바꾸거나 인터럽트를 내는 기능이다. 이 예제설명은 카운터를 멈추지 않고 돌리면서 ISR이 CCR을 앞으로 옮기는 CCR 전진 기법으로 한 타이머에서 채널마다 다른 주파수를 만드는 04_TIM_OutputCompare 예제를 해석한다.

1. 문제: 한 타이머에서 채널마다 다른 주기

타임베이스(01)는 ARR 하나로 주기를 정하므로 모든 이벤트가 같은 주기를 갖는다. 출력 비교는 채널마다 비교값(CCRx)이 따로 있어 서로 다른 시각에 이벤트를 만든다.

  • CNT == CCRx일 때 하드웨어가 출력을 바꾸거나 인터럽트를 내는 원리를 이해한다.
  • Toggle 모드와 Timing(Frozen) 모드를 구분한다.
  • CCR 전진 기법으로 채널마다 다른 주파수를 만든다.
  • PWM(05)이 출력 비교의 한 모드(OCxM = 110)임을 이해한다.
  • 핀 충돌(TIM2_CH3 = PA2 = USART2_TX)을 피하는 방법을 익힌다.

3. CCR 전진 기법

카운터는 멈추지 않고 계속 돈다. 비교 인터럽트가 날 때마다 ISR에서 CCRx += 간격을 수행하여 다음에 일어날 시각만 정한다. ARR = 0xFFFF이므로 uint16_t 덧셈의 래핑이 카운터의 래핑과 정확히 맞는다.

그림 1. Toggle 모드: CNT == CCR1이 되는 순간 하드웨어가 출력을 반전하고, ISR이 CCR1에 간격을 더해 다음 시각을 정한다. (자유 계수 CNT 0~0xFFFF 중 앞부분만 확대하여 표시)

Toggle 출력 주파수 f = f_tick / (2 × HALF) (f_tick = 64 MHz / (PSC+1) = 10 kHz)

6. HAL 흐름과 핀 충돌

  1. 1
    CNT == CCRx하드웨어하드웨어가 출력을 반전하고(Toggle) SR.CCxIF를 세운다.
  2. 2
    DIER.CCxIE 확인하드웨어허용되어 있으면 NVIC TIM2_IRQn으로 전달된다.
  3. 3
    HAL_TIM_IRQHandler소프트웨어CCxIF를 지우고 CCxS = 00(출력)이면 콜백을 호출한다.
  4. 4
    HAL_TIM_OC_DelayElapsedCallback소프트웨어htim->Channel로 채널을 구분하고 CCRx += 간격을 수행한다.
  • HAL_TIM_OC_ConfigChannel()은 OCxPE(CCR 프리로드)를 켜지 않는다. ISR에서 쓴 CCRx가 즉시 다음 비교값이 된다. PWM 설정 함수는 OCxPE = 1로 켠다.
  • 한 번 진입했을 때 여러 플래그가 서 있으면 CH1 → CH2 → CH3 순서로 콜백이 차례로 불린다.
핀 충돌

TIM2_CH3의 기본 핀은 PA2이며 USART2_TX와 같다. HAL_TIM_OC_Start_IT(CH3)은 CC3E = 1로 출력까지 켜므로 쓰지 않고, __HAL_TIM_ENABLE_IT()로 인터럽트만 켠다. F1은 한 핀을 두 주변장치가 동시에 구동하면 충돌한다.

7. 코드 읽기

회로는 05_TIM_PWM과 같다. LD2(PA5)와 B1(PC13)은 보드에 내장되어 있다.

PA0 (A0) ── 330 Ω ── 외부 LED 1 ── GND
PA1 (A1) ── 330 Ω ── 외부 LED 2 ── GND
main.c — 타이머·채널 초기화
static void MX_TIM2_Init(void)
{

  TIM_ClockConfigTypeDef sClockSourceConfig = {0};
  TIM_MasterConfigTypeDef sMasterConfig = {0};
  TIM_OC_InitTypeDef sConfigOC = {0};

  htim2.Instance = TIM2;
  htim2.Init.Prescaler = 6399;
  htim2.Init.CounterMode = TIM_COUNTERMODE_UP;
  htim2.Init.Period = 65535;
  htim2.Init.ClockDivision = TIM_CLOCKDIVISION_DIV1;
  htim2.Init.AutoReloadPreload = TIM_AUTORELOAD_PRELOAD_DISABLE;
  if (HAL_TIM_Base_Init(&htim2) != HAL_OK)
  {
    Error_Handler();
  }
  sClockSourceConfig.ClockSource = TIM_CLOCKSOURCE_INTERNAL;
  if (HAL_TIM_ConfigClockSource(&htim2, &sClockSourceConfig) != HAL_OK)
  {
    Error_Handler();
  }
  if (HAL_TIM_OC_Init(&htim2) != HAL_OK)
  {
    Error_Handler();
  }
  sMasterConfig.MasterOutputTrigger = TIM_TRGO_RESET;
  sMasterConfig.MasterSlaveMode = TIM_MASTERSLAVEMODE_DISABLE;
  if (HAL_TIMEx_MasterConfigSynchronization(&htim2, &sMasterConfig) != HAL_OK)
  {
    Error_Handler();
  }
  sConfigOC.OCMode = TIM_OCMODE_TOGGLE;
  sConfigOC.Pulse = 2500;
  sConfigOC.OCPolarity = TIM_OCPOLARITY_HIGH;
  sConfigOC.OCFastMode = TIM_OCFAST_DISABLE;
  if (HAL_TIM_OC_ConfigChannel(&htim2, &sConfigOC, TIM_CHANNEL_1) != HAL_OK)
  {
    Error_Handler();
  }
  sConfigOC.Pulse = 1000;
  if (HAL_TIM_OC_ConfigChannel(&htim2, &sConfigOC, TIM_CHANNEL_2) != HAL_OK)
  {
    Error_Handler();
  }
  sConfigOC.OCMode = TIM_OCMODE_TIMING;
  sConfigOC.Pulse = 10000;
  if (HAL_TIM_OC_ConfigChannel(&htim2, &sConfigOC, TIM_CHANNEL_3) != HAL_OK)
  {
    Error_Handler();
  }
  /* PSC=6400-1 -> 10kHz, ARR=0xFFFF 자유 계수, ARPE=0.
   * CH1/CH2: CCMR1.OCxM=011(Toggle), CH3: CCMR2.OC3M=000(Frozen=Timing).
   * HAL_TIM_OC_ConfigChannel 은 OCxPE(프리로드)를 켜지 않는다 -> ISR 에서 쓴 CCRx 가 즉시 다음 비교값이 된다. */
  HAL_TIM_MspPostInit(&htim2);

}
  1. Prescaler 6399로 10 kHz 틱을 만든다.
  2. CH1·CH2는 Toggle, CH3은 Timing 모드이다.
  3. Pulse가 첫 비교 시각이다.
main.c — 시작 순서
__HAL_TIM_ENABLE_IT(&htim2, TIM_IT_CC3);

/* CH1, CH2 = Toggle 모드: DIER.CCxIE=1, CCER.CCxE=1, CR1.CEN=1 */

main.c — 콜백: CCR 전진
void HAL_TIM_OC_DelayElapsedCallback(TIM_HandleTypeDef *htim)
{
  if (htim->Instance != TIM2) return;

  switch (htim->Channel)
  {
  case HAL_TIM_ACTIVE_CHANNEL_1:   /* 핀 반전은 하드웨어가 이미 했다. 다음 반전 시각만 정한다 */
    __HAL_TIM_SET_COMPARE(htim, TIM_CHANNEL_1,
        (uint16_t)(__HAL_TIM_GET_COMPARE(htim, TIM_CHANNEL_1) + CH1_HALF));   /* TIM2->CCR1 += 2500 */
    break;

  case HAL_TIM_ACTIVE_CHANNEL_2:
    __HAL_TIM_SET_COMPARE(htim, TIM_CHANNEL_2,
        (uint16_t)(__HAL_TIM_GET_COMPARE(htim, TIM_CHANNEL_2) + gHalf2));     /* TIM2->CCR2 += gHalf2 */
    break;

  case HAL_TIM_ACTIVE_CHANNEL_3:   /* Timing 모드: 핀 변화 없음, "정해진 시각의 인터럽트"로만 쓴다 */
    __HAL_TIM_SET_COMPARE(htim, TIM_CHANNEL_3,
        (uint16_t)(__HAL_TIM_GET_COMPARE(htim, TIM_CHANNEL_3) + CH3_INTERVAL)); /* TIM2->CCR3 += 10000 */
    HAL_GPIO_TogglePin(LD2_GPIO_Port, LD2_Pin);   /* 짧은 GPIO 작업은 ISR 에서 해도 된다 */
    gSec++;
    gSecFlag = 1;                                  /* printf 는 main 루프에서 */
    break;

  default:
    break;
  }
}
  1. CH1·CH2는 핀 반전을 하드웨어가 이미 수행했으므로 다음 반전 시각만 정한다.
  2. CH3은 핀 변화 없이 1초마다 LD2를 토글하고 보고 플래그를 세운다. printf는 main 루프에서 한다.
  3. gHalf2는 main이 쓰고 ISR이 읽는 16비트 변수이다 (Cortex-M3에서 16비트 쓰기는 원자적).
B1 버튼과 CH2 주파수 변경

main 루프가 B1(PC13, 눌리면 0)의 하강 에지를 폴링하고 50 ms 디바운스 후 HALF 후보 표 {1000, 500, 250, 2500}를 순환한다. 새 값은 다음 CH2 비교부터 적용된다.

8. 실험

실험 A. 지연으로 채널 멈추기

콜백 안에 HAL_Delay() 대신 짧은 반복문으로 지연을 넣어 CH2가 멈추는 최소 지연을 측정한다. 시뮬레이터의 예측과 비교한다.

실험 B. 틱 주파수 올리기

PSC=63(1 MHz)으로 바꾸고 HALF=500, 250으로 설정해 1 kHz, 2 kHz가 나오는지 확인한다. CH3 간격 10000은 몇 ms인가?

실험 C. 듀티 바꾸기

반전할 때마다 High 간격과 Low 간격을 번갈아 더하도록 바꾸어 50%가 아닌 듀티를 만든다.

실험 D. CCER 확인

시작 후 출력되는 CCMR1/CCMR2/CCER/DIER 값을 5절의 표와 대조한다.

10. 확인 문제

문제 1. 콜백에서 오래 머물면 왜 채널이 멈추는가? 멈추는 시간은?

다음 일치 시각이 이미 지나갔으므로 CNT가 한 바퀴 돌아 다시 CCR과 같아질 때까지 기다려야 한다. 6.5536 s이다.

문제 2. 듀티 50%가 아닌 파형을 만들려면?

반전할 때마다 High 간격과 Low 간격을 번갈아 더한다. 주파수와 듀티가 고정이면 PWM이 더 간단하다.

문제 3. PSC = 63(1 MHz), HALF = 500, 250이면 각각 몇 Hz인가? CH3 간격 10000은 몇 ms인가?

1 kHz, 2 kHz이다. 10000 tick × 1 µs = 10 ms이다.

문제 4. Toggle 대신 Active/Inactive 모드를 번갈아 쓰면 듀티를 바꿀 수 있는가?

가능하다. 일치마다 OCxM을 Active on match와 Inactive on match로 바꾸고 High·Low 간격을 따로 더한다.
