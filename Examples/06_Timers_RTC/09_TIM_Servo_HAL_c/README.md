# 09_TIM_Servo_HAL_c

> 계층: **HAL** — Claude 작성, 검토 전 (PlatformIO 빌드만 확인)

**RC 서보** 제어: 50Hz PWM, **펄스 폭 1.0~2.0ms = 0~180°**. 각도 정확도는 하드웨어 타이머가 만드는 펄스 폭의 정확도가 정한다.

## 핵심 학습 내용

- **타이머**: TIM2_CH1(PA0), PSC=64-1(1MHz), ARR=20000-1(20ms), `CCR1 = 펄스 폭[us] = 1000 + 각도×1000/180`. 분해능 1us ≈ 0.18°.
- **서보 편차**: 0.5~2.5ms 까지 도는 서보도 있다. 기계적 한계에서 떠는 소리가 나면 `PULSE_MIN/MAX_US` 범위를 좁힌다.
- **모드**(B1): 스윕 → 중앙 90° → 0° → 180° → 스윕. 고정 모드에서도 PWM 이 계속 나와야 위치를 유지한다.
- **전원 주의**: 서보 전원은 **외부 5V**(GND 공통). Nucleo 핀에서 끌어 쓰면 스파이크로 보드가 리셋될 수 있다.

## 배선 / 동작

신호선(주황/노랑)=PA0, 전원(빨강)=외부 5V, GND 공통. 0.5초마다 각도/펄스 폭을 UART(115200)로 출력.

## ISR vs 콜백

인터럽트를 사용하지 않는다.
