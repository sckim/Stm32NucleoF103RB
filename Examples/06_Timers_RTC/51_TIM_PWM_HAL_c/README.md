# 51_TIM_PWM_HAL_c

> 계층: **HAL** + TIM — Claude 작성, 검토 전 (컴파일만 확인)

TIM2_CH1(PA0)에 1kHz PWM을 출력하고 듀티를 0~100%로 왕복시켜 LED를 숨쉬듯 점멸시킨다.

## 핵심 학습 내용

- **PWM 주파수/듀티 계산**: TIM2 클럭 64MHz(APB1 32MHz, 분주비 ≠ 1이라 ×2). `PSC = 63` → 1MHz, `ARR = 999` → 1kHz, `CCR1` = 듀티 카운트 → 듀티% = `CCR1 / (ARR+1) × 100`.
- **레지스터 대응**: `CCMR1.OC1M = 110`(PWM 모드 1), `CCER.CC1E = 1`(출력 활성), `TIM2->CCR1`.
- **하드웨어 PWM의 장점**: 파형은 타이머 하드웨어가 생성하므로 CPU는 `CCR1`만 바꾸면 되고 인터럽트가 필요 없다.
- **서보 응용**: PSC=63, ARR=19999(20ms = 50Hz), `CCR1 = 1000~2000`(1~2ms 펄스).
- **핀 제약**: 온보드 LD2(PA5)는 타이머 채널이 아니라 PWM 불가 → 외부 LED가 필요하다.

## 배선

`PA0(A0) ── 330Ω ── 외부 LED ── GND`

## 동작

듀티가 왕복하며 LED 밝기가 변한다. 스코프/로직 분석기로 PA0 파형(1kHz, 듀티 변화)을 관찰할 수 있다.

## 인터럽트

사용하지 않는다.

## 관련 예제

`53`(상보 PWM), `08_Clock_System/73_AFIO_Remap_Reg_c`(PWM 핀 리맵).
