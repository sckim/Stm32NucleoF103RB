# 52_TIM_InputCapture_HAL_c

> 계층: **HAL** + TIM — Claude 작성, 검토 전 (컴파일만 확인)

TIM2 입력 캡처로 외부 신호의 주기/주파수를 측정한다. 테스트 신호는 TIM3이 스스로 만든 1kHz PWM이다.

## 핵심 학습 내용

- **입력 캡처 원리**: 상승 에지마다 카운터(`CNT`) 값이 `CCR1`에 래치(캡처)된다. **연속된 두 캡처 값의 차 = 주기(카운트)**.
- **오버플로 안전 계산**: 16비트 카운터이므로 `uint16_t` 뺄셈이 오버플로 1회를 자동으로 처리한다.
- **측정 범위**: 카운터 클럭 1MHz(PSC=63), `ARR=0xFFFF` → 분해능 1µs, 최저 측정 주파수 ≈ 1MHz/65536 = 15.3Hz. 입력 주파수에 맞춰 PSC를 조정.
- **테스트 신호 자급**: TIM3_CH1(PA6)이 1kHz/50% PWM을 출력 → 점퍼로 PA0에 연결. 다른 신호를 재려면 PA0에 직접 연결.
- 인터럽트 방식이라 한 번의 에지에 한 번 ISR이 호출된다 (고주파 신호에는 부하가 커짐 → 다음 단계 `55`).

## 배선

`PA6(D12) ── 점퍼 ── PA0(A0)`

## 동작

0.5초마다 측정한 주파수를 UART(115200)로 출력 (1000Hz 근처).

## ISR vs 콜백

`TIM2_IRQHandler`(진짜 ISR) → `HAL_TIM_IRQHandler()` → `HAL_TIM_IC_CaptureCallback()`(이 파일): `SR.CC1IF` 발생 시 호출되므로 ISR 문맥에서 짧게 처리.

## 관련 예제

`55_TIM_PWMInput_HAL_c`(하드웨어로 자동화), `57`(에코 폭 측정).
