# 91_CRC_Unit_HAL_c

> 계층: **HAL** + CRC — Claude 작성, 검토 전 (컴파일만 확인)

하드웨어 CRC 계산 유닛을 사용하고, 소프트웨어 구현과 결과·속도를 비교한다.

## 핵심 학습 내용

- **F1 CRC 유닛의 고정 사양** (RM0008 11장): 다항식 `0x04C11DB7`, 초기값 `0xFFFFFFFF`, 입력/출력 비트 반전 없음, 최종 XOR 없음 → 표준명 **CRC-32/MPEG-2**. 입력은 32비트 워드 단위로 `CRC->DR`에 쓰고 결과를 `CRC->DR`에서 읽는다 (1워드 4 AHB 사이클).
- **주의**: zlib/PNG/ZIP이 쓰는 표준 CRC-32는 입력·출력 비트 반전과 최종 XOR이 있어 **값이 다르다.** (이후 STM32 시리즈는 설정 가능하지만 F1은 불가능)
- **하드웨어 대응**: `CRC->CR.RESET`(bit0)=1로 `DR`을 초기값으로, `CRC->IDR`(범용 1바이트), `RCC->AHBENR.CRCEN`(bit6) 클럭 허용.
- **CRC의 오류 검출 능력**: 데이터 1비트만 바꿔도 CRC가 완전히 달라진다.

## 동작

1. 256워드(1KB) 데이터의 CRC를 HW(`HAL_CRC_Calculate`)와 SW(비트 단위 루프)로 계산해 결과 일치를 확인 (PASS/FAIL)
2. 두 방식의 소요 시간을 DWT 사이클로 측정해 비교 (HW가 수십 배 빠름)
3. 데이터 1비트를 바꿔 CRC가 달라지는 것을 확인

## 활용

펌웨어 무결성 검사(부트로더가 Flash 전체 CRC 확인), 통신 프레임 검사, Flash 저장 데이터 유효성 표시.

## 인터럽트

사용하지 않는다.

## 관련 예제

`90_Flash_Write_HAL_c`(저장 데이터 보호에 적용), `08_Clock_System/77_DWT_Profiling_Reg_c`(시간 측정).
