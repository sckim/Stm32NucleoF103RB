# 03_Link_PWM_Meter_HAL_c

> 계층: **HAL** + TIM (STM32CubeMX 생성 프로젝트, `06_Timers_RTC/05_TIM_PWM` 기반)

**TIM1_CH1(PA8 = D7)** 에 1 kHz PWM을 내고 듀티를 3초마다 10, 25, 50, 75, 90 %로 바꾼다. DE1-SoC의 `fpga/lab3_top.v`가 주기와 High 시간을 0.1 us 단위로 재어 HEX5~HEX0에 10진수로 표시한다.

절차는 [실습 매뉴얼](../13_DE1SoC_Link%20실습매뉴얼.html)의 「실습 3」에 있다.

## 원본 예제에서 바뀐 것

| 영역 | 변경 |
|---|---|
| `USER CODE 1` | 쓰지 않는 변수 `duty`, `step` 삭제 |
| `USER CODE 3` | 듀티 왕복 대신 `CCR1`을 표의 값 다섯 개로 3초마다 변경 |

## 배선

| Nucleo | DE1-SoC JP1 |
|---|---|
| D7 (PA8, TIM1_CH1) | 3번 핀 (GPIO_0[2], PIN_AD17) |
| GND | 12번 핀 (GND) |

**D2 선은 빼 둔다.** `.ioc` 설정대로 TIM1_CH3(PA10 = D2)에도 PWM 출력이 켜진다. 실습 2의 FPGA 회로는 같은 선을 출력으로 구동하므로 두 출력이 맞부딪힌다.

## PWM 계산

- TIM1 클럭 64 MHz, `PSC = 63` → 1카운트 = 1 us, `ARR = 999` → 주기 1000 us(1 kHz)
- `CCR1` = High 시간(us), 듀티 = `CCR1 / (ARR + 1)`
- `CCMR1.OC1M = 110`(PWM 모드 1), `CCER.CC1E = 1`, `BDTR.MOE = 1`(`HAL_TIM_PWM_Start`가 세트)

## 인터럽트

사용하지 않는다. 파형은 타이머 하드웨어가 만들고 CPU는 3초에 한 번 `CCR1`만 바꾼다.

## 기대 결과

| CCR1 | 주기 표시(SW0 = 0) | High 표시(SW0 = 1) | 듀티 |
|---|---|---|---|
| 100 | 010000 | 001000 | 10 % |
| 250 | 010000 | 002500 | 25 % |
| 500 | 010000 | 005000 | 50 % |
| 750 | 010000 | 007500 | 75 % |
| 900 | 010000 | 009000 | 90 % |

MCU가 내부 RC 발진기(HSI)를 쓰므로 주기는 `010000`에서 조금 벗어난다. 듀티는 영향을 받지 않는다.
