처음 한 번은 Clone(클론)으로 저장소를 내 컴퓨터에 복사한다. 그 이후부터는 자료가 업데이트되면 Pull(풀)로 최신 내용을 가져온다.

준비물

  • Visual Studio Code 설치
  • Git 설치 (VS Code가 Git을 사용한다. 설치 안내나 Git not found 오류가 나오면 담당자에게 문의한다.)
  • 인터넷 연결
  • 저장소 주소: https://github.com/sckim/Stm32NucleoF103RB

저장소는 공개되어 있으므로 자료를 내려받는 데 보통 GitHub 로그인이 필요하지 않다. 내려받기만 할 때는 Push로 변경 사항을 올리지 않는다.

1. 처음 한 번: VS Code에서 클론하기

클론은 GitHub 저장소와 변경 이력을 내 컴퓨터에 처음 복사하는 작업이다. 컴퓨터마다 한 번만 하면 된다.

  1. VS Code를 실행한다.
  2. 키보드에서 Ctrl + Shift + P를 눌러 명령 팔레트를 연다.
  3. Git: Clone을 입력하고 같은 이름의 명령을 선택한다.
    명령 팔레트
    > Git: Clone
  4. 저장소 주소를 붙여넣고 Enter를 누른다.
    https://github.com/sckim/Stm32NucleoF103RB
  5. 저장소를 둘 위치(예: 문서/Documents)를 선택한다. 저장소 폴더가 만들어질 상위 폴더를 선택하면 된다. 같은 이름의 폴더가 이미 있으면 다른 위치를 고른다.
  6. 클론이 끝나면 Open(열기) 또는 Open in New Window(새 창에서 열기)를 선택한다.
  7. 왼쪽 Explorer(탐색기)에 Docs, Examples, Schematics 폴더가 보이면 완료된 것이다.

보안 안내가 나오면 저장소가 수업에서 안내된 주소와 일치하는지 확인한다. 신뢰할 수 있는 출처임을 확인한 경우에만 Trust(신뢰)를 선택한다.

2. 수업 중 최신 자료 받기: Pull

선생님이 GitHub의 저장소를 수정해도 내 컴퓨터의 폴더는 자동으로 바뀌지 않는다. 수업 시작 전이나 업데이트 공지가 있을 때 아래 절차를 실행한다.

방법 A — VS Code 메뉴 사용(추천)

  1. VS Code에서 클론한 Stm32NucleoF103RB 폴더가 열려 있는지 확인한다. 다른 폴더라면 File > Open Folder에서 저장소 폴더를 연다.
  2. 왼쪽 가지 모양 Source Control(소스 제어) 아이콘을 누른다. 단축키는 Ctrl + Shift + G이다.
  3. …(더 보기) 메뉴에서 Pull을 선택한다. 메뉴에서 찾기 어렵다면 Ctrl + Shift + P를 누르고 Git: Pull을 실행한다.
  4. 완료 메시지를 확인한다. 다음 메시지는 이미 최신 상태라는 뜻이다.
    Already up to date.
    파일 목록에 새 파일이 보이면 업데이트가 반영된 것이다.
찾는 길
왼쪽 Source Control → … 메뉴 → Pull
또는 Ctrl + Shift + P → “Git: Pull” 입력 → Enter

VS Code 버전에 따라 메뉴 배치가 다를 수 있다. 이 저장소의 기본 브랜치는 main이다. 학생은 우선 Git: Pull을 사용한다. Sync Changes는 로컬 변경 사항을 Push할 수도 있으므로, 수업 지시가 없다면 누르지 않는다.

방법 B — 터미널 명령 사용

  1. VS Code 메뉴에서 Terminal > New Terminal을 선택한다.
  2. 터미널이 저장소 폴더 안에서 열렸는지 확인한다. 다른 폴더라면 Explorer에서 Stm32NucleoF103RB 폴더를 마우스 오른쪽 버튼으로 눌러 Open in Integrated Terminal을 선택한다.
  3. 아래 명령을 입력하고 Enter를 누른다.
    git pull origin main
  4. Already up to date.가 나오면 이미 최신이다. 파일 변경 요약이 나오면 새 내용이 적용된 것이다.

3. 처음 클론할 때 터미널을 사용하고 싶다면

VS Code에서 Terminal > New Terminal을 연 다음, 예를 들어 Documents 폴더에 저장하려면 다음을 입력한다.

cd $HOME\Documents
git clone https://github.com/sckim/Stm32NucleoF103RB.git

완료 후 File > Open Folder를 선택하고 Documents 안의 Stm32NucleoF103RB 폴더를 연다. 처음이라면 앞의 VS Code 메뉴를 이용한 클론 방법을 권장한다.

4. 자주 만나는 상황

화면/상황뜻과 할 일
Already up to date.현재 브랜치가 원격 저장소와 같다. 정상이다.
Pull 후 새 파일이 안 보임Explorer 새로고침을 누르고, 올바른 저장소 폴더가 열렸는지 확인한다. GitHub 웹페이지와 내 컴퓨터의 폴더는 별개이다.
로컬 변경 때문에 Pull이 중단됨내 컴퓨터에서 수정한 내용이 있어 Git이 덮어쓰기를 막은 것이다. 파일을 지우거나 덮어쓰지 말고 담당자에게 문의한다.
Merge conflict / 충돌내 파일과 GitHub 파일의 같은 부분이 서로 다르게 바뀌었다. 임의로 선택하지 말고 담당자에게 문의한다.
Git not foundGit이 설치되지 않았거나 VS Code가 아직 인식하지 못할 수 있다. 담당자에게 설치 도움을 요청한다.
Push 또는 로그인 안내가 나옴공개 자료를 받는 데 Push는 필요하지 않다. 권한 요청이나 코드 업로드 전에 담당자의 안내를 확인한다.

5. 수업 시작 전 20초 체크리스트

  • VS Code에서 Stm32NucleoF103RB 폴더를 열었다.
  • Source Control > … > Pull 또는 Ctrl + Shift + P > Git: Pull을 실행했다.
  • 오류가 없거나 Already up to date. 메시지를 확인했다.
  • 새 실습 파일이 필요하면 Examples 폴더에서 찾았다.
  • 실습 지시가 없다면 Push / Sync Changes를 누르지 않았다.
